Stubs can be customised: `php artisan vendor:publish --tag=alfakit-stubs` copies them to `stubs/alfakit/`.

Generators that write frontend files (`make:alfakit-field|column|entry|schema-component|widget|page`, `alfakit:eject`, `alfakit:realtime`'s `echo.ts`, `alfakit-forms:page`, `alfakit-helpdesk:pages`) format them with the app's own formatter when one is configured: `node_modules/.bin/vp fmt` (a `fmt` section in `vite.config`), Oxfmt (`.oxfmtrc.json`) or Prettier (a Prettier config). `config('alfakit.file_generation.format_frontend')` (default `true`) turns this off.

## Publish tags

| Tag                                | Publishes                                                                |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `alfakit-config`                   | `config/alfakit.php` (`alfakit:install` does this for you)               |
| `alfakit-translations`             | The language files, to `lang/vendor/alfakit`                             |
| `alfakit-views`                    | The root view and other Blade views, to `resources/views/vendor/alfakit` |
| `alfakit-stubs`                    | The generator stubs, to `stubs/alfakit`                                  |
| `alfakit-import-export-migrations` | The migrations for imports, exports and failed import rows               |

```bash
php artisan vendor:publish --tag=alfakit-config
```

## Customising generated classes

Every generator renders its stub through `AlfaSix\Alfakit\Commands\Generators\ClassGenerator`, resolved from the container. Bind a subclass to change what is written, for every file or per stub (`resource`, `pages/edit`, `relation-manager`, `standalone/form`, `widgets/stats`…); `modify()` receives the stub name, the contents with the placeholders replaced, and the replacements:

```php
use AlfaSix\Alfakit\Commands\Generators\ClassGenerator;

class AppClassGenerator extends ClassGenerator
{
    protected function modify(string $stub, string $contents, array $replacements): string
    {
        // Every generated resource gets an attribute.
        return $stub === 'resource'
            ? str_replace("\nclass ", "\n#[\\App\\Attributes\\Audited]\nclass ", $contents)
            : $contents;
    }
}

// AppServiceProvider::register()
$this->app->bind(ClassGenerator::class, AppClassGenerator::class);
```

Published stubs still apply first; `stubPath()` can be overridden to read stubs from elsewhere.

The `make:alfakit-*` generators added for themes, fields, columns, entries and plugins are also available as `alfakit:make-theme`, `alfakit:make-field`, `alfakit:make-column`, `alfakit:make-entry` and `alfakit:make-plugin`. The field, column and entry generators pick the adapter from `@alfakit/*` (or `@inertiajs/*`) in `package.json` when `--adapter` is not given.
