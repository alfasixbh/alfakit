# 1,000,000-row table benchmark (2026-10-18)

Server TTFB (median of 9 after 1 warm-up, sequential, full HTML page load) and response size, 25 rows per page, SQLite. Results vary by hardware.

Laravel caches: `php artisan optimize` in every app (config, events, routes, views, `alfakit:optimize` / `filament:optimize`). APP_DEBUG off, Inertia SSR and devtools off, database sessions in every app. AlfaKit "lean" is the playground's /bench panel (benchmark resources only, no plugins, Filament's default middleware); "full" is /admin with every playground plugin.

Hardware: Mac17,2 Apple M5 (10 cores), 16 GB, macOS 27.0 (26A428), PHP 8.4.23, Node v22.23.0, Herd Herd 1.30.2. Load average before 3.69 / 3.27 / 3.25, after 3.21 / 3.17 / 3.2; 1-minute load when each target started: react 2.88, vue 2.96, svelte 2.95, filament 2.97.
