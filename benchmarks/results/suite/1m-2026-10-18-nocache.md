# 1,000,000-row table benchmark (2026-10-18)

Server TTFB (median of 5 after 1 warm-up, sequential, full HTML page load) and response size, 25 rows per page, SQLite. Results vary by hardware.

Laravel caches: none (`optimize:clear` in every app). APP_DEBUG off, Inertia SSR and devtools off, database sessions in every app. AlfaKit "lean" is the playground's /bench panel (benchmark resources only, no plugins, Filament's default middleware); "full" is /admin with every playground plugin.

Hardware: Mac17,2 Apple M5 (10 cores), 16 GB, macOS 27.0 (26A428), PHP 8.4.23, Node v22.23.0, Herd Herd 1.30.2. Load average before 3.08 / 3.04 / 3.26, after 2.73 / 2.94 / 3.21; 1-minute load when each target started: react 2.91, vue 2.89, svelte 2.92, filament 2.71.
